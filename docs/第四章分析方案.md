# 第四章实验方案（新增转向阶段结果计算前固定）

本次为已有回报数据的探索性再分析，不是新的全球模式试验，也不是事前注册研究。已有120 h总体及分组结果已知；本方案在检查时间、分组及样本支持度后、计算新增阶段差值前固定。不为获得显著性改变窗口或样本。原数据与原论文保留。

## 数据及可重复性

使用归档中心坐标、案例目录、JMA路径。首先核对模型间完整配对，独立重算球面距离及ATE/CTE，重新运行转向规则，对照原归档结果；发现不一致先查明。输入复制到inputs并记录SHA-256。主分析仅14台风74完整案例；其他13台风不加入主结果。

DPE使用归档到0.01 km的距离，独立大圆距离重算容差0.00501 km。ATE/CTE按当前JMA中心回看12 h确定方向，位移小于10 km的记录仅排除方向分解。另计算前后各6 h方向及平行移动转向时刻参考方向的敏感性版本。单位均km。所有排除及样本数输出。

## E1：误差方向的完整时效变化

6–120 h每6 h报告平均DPE、有符号ATE/CTE、平均绝对ATE/CTE、沿轨平方误差占比。先台风内平均案例，再台风等权。14台风完整向量联合bootstrap 20000次，随机种子20261018按任务键派生；报告逐时效95%百分位区间。

绝对ATE−绝对CTE为直接比较对象，构建覆盖3模型×20时效的60坐标固定标准误max-bootstrap近似95%同时置信带，不以边际区间重叠代替差值检验。24–120 h净增长在两个端点均有效的共同案例上计算，3模型×3指标（DPE、绝对ATE、绝对CTE）作为9坐标家族；是端点净增长，不是单调增长或台风速度。

## E2：识别转向

只用JMA资料，沿用归档1°规则：TS及以上候选，前后24 h连续6 h等级2–5，先西后东各至少1°经度、两段均北移，并满足前后各两个12 h时段的经度方向一致。候选选最西、再最早。重算全部27台风，主分析5个转向台风与9个未检出转向台风。输出每个台风的候选时刻、判定量及最终时刻。

## E3：转向前后误差变化（新增核心）

两个时钟分开：lead为起报后小时数；r为验证时刻减JMA转向时刻。主窗口固定为转向前r∈[-24,-12]、附近r∈[-6,6]、之后r∈[12,24]，含端点。

主阶段分析只保留起报严格早于转向时刻的预报，避免用转向后初始化替代对转向过程的预报。前后对比先在同一台风、同一模型、同一lead分别求阶段均值，再计算“后−前”；仅保留前后都有记录的台风×lead。三模型及五个指标使用共同有效记录，先在每个台风各自可匹配的lead上等权，再对5个台风等权。

时间支持度核查已显示：五台风可匹配lead集合不相同，同一lead最多支持2台风，五台风没有共同可匹配lead。因此：汇总目标明确为“这5个台风各自可匹配时效中的平均前后变化”，不是统一72 h或120 h效应。逐lead结果仅作描述，不在n=1–2时作显著性推断；每个台风差值必须展示。

主要指标为DPE、绝对ATE、绝对CTE，3模型×3指标共9项。对5台风枚举全部5^5=3125种有放回抽样序列，得到经验bootstrap百分位区间和9项近似同时置信带；“枚举完整”仅消除Monte Carlo误差，不保证小样本覆盖率准确。有符号ATE、CTE及附近−前、后−附近作为次要描述。

另作5台风符号翻转枚举（2^5=32种），在台风独立且零假设下差值向量可对称翻转的附加假设下，计算双侧均值检验及9项max-|t|调整p值。阶段不是随机分配，故不称随机对照或因果置换检验；最小双侧未调整p值为2/32=0.0625。本检验用于暴露小样本信息分辨率，不据此宣布模型等效。

敏感性：①逐一删除5台风；②前后窗口扩至48 h（仍排除±6 h核心区）；③允许所有起报时刻；④使用前后各6 h参考方向；⑤将转向时刻切向基向量沿球面最短路径平行移动到各验证位置，冻结参考方向以检查坐标旋转影响。方向比较均使用共同有效记录，输出匹配键；不从五种设置中挑显著结果。

未经lead匹配的阶段均值仅作辅助表，并同时报告lead分布，不能把原始阶段曲线当作转向影响。

## E4：路径类型与模型差异

同一模型比较5个转向台风与9个未检出转向台风。按时效报告DPE、绝对ATE、绝对CTE；每组内独立重采样整台风20000次，保留跨模型、跨时效相关。组间“转向−其余”差值的3模型×3指标×20时效共180坐标组成同时比较家族。

各组内部3组模型配对×3指标×20时效×2组共360坐标为第二家族；模型配对差的组间交互3配对×3指标×20时效共180坐标为第三家族。分别报告逐项与各家族近似同时区间；不同家族不宣称共同全章95%覆盖。比较有方向分量时使用相同有效记录。逐一删除台风并重算120 h分组差异，明确HALONG的影响。

## 解释边界与图表

四步叙述：总体误差方向→转向识别→匹配时效的阶段对比→两类台风及模型差异。结论可以提升到“总体指标遗漏的方向/条件差异”“风险识别应考虑阶段与个例异质性”，但不得将ATE直接解释为纯速度误差、阶段关联解释为转向因果作用，或用事后JMA阶段直接给业务预警。
