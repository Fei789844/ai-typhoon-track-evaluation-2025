# 程序说明

## 本次新增计算

在本材料根目录运行：

```bash
python3 code/derive_rmse.py
```

需要Python、NumPy、pandas。程序读取随附`data/error_components_cases.csv`和`data/overall_by_lead.csv`，生成`data/rmse_by_lead.csv`及`data/rmse_audit.json`。此次实际运行的软件版本记录在audit文件。它仅计算距离RMSE与逐时效置信区间，不执行AI模型推理、中心追踪或RMSE差值的显著性检验。

## 原分析程序归档

`原分析程序`保存来自原项目的程序副本，没有修改其算法与路径假定。用途如下：

| 文件 | 用途 |
|---|---|
| experiment1.py | 平均DPE与台风bootstrap |
| experiment2.py | DPE配对差值与60项比较同时置信带 |
| experiments3to6.py | 误差分解、转向分组、分歧与留出台风风险识别 |
| supplement.py | 分组误差分量、组间差值及其他敏感性结果 |
| tracker_source.py / tracker_deterministic.py | 中心追踪与确定性候选排序 |
| retrack_verified.py | 同一气象场的连续重追踪与参数对照 |
| field_diagnostics.py | 高影响案例的原始场检查与绘图 |
| verify_*.py | 原流程的统计、几何或重追踪核对 |
| run_all.py | 原项目分析流程入口 |

原运行目录为：

原研究工程根目录（通过命令行参数传入）

其中部分程序按所在目录解析原项目的案例目录、JMA表和GRIB路径，因而不能把此次归档副本当成独立完整的软件发行包直接运行。原工程输入与路径信息保存在原项目以及本目录`核对材料/原复现记录`中。本次配套材料完整支持新增RMSE的重算，原追踪流程仍需对应气象场文件；没有再次执行原全球AI模型。

`validate_revision.py`用于核对本次稿件的本地链接、引文锚点、关键表格数值与RMSE重复运行结果。其检查记录保存在`核对材料/本次验证结果.json`。
