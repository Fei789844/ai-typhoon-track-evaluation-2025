# 13个截短台风补充分析

本目录分析主样本之外的13个台风。每个台风保留一个36–108 h起报案例，在两批样本共同覆盖的6–36 h窗口内比较三模型DPE，并报告42–78 h随有效台风数变化的描述结果。

```bash
python supplement_13/code/analyze_short.py
python supplement_13/code/verify_short.py
python supplement_13/code/plot_short.py
```

分析方案见[`docs/13个截短台风补充分析方案.md`](../docs/13个截短台风补充分析方案.md)。
